# Simple Pomodoro and Task Timer

Pythonの標準GUIライブラリ tkinter を用いて開発した、作業集中および実績記録のためのポモドーロタイマーアプリケーションです。

## 1. 目的と概要
* ターゲット: デスクトップ環境で集中力を高めたい個人
* 目的: 25分の作業タイマーと5分の休憩タイマーを切り替えながら作業に没頭し、カテゴリごとに簡単な作業内容と実施サイクル数を記録・振り返ることで達成感を可視化する。

## 2. 主要機能
* ポモドーロタイマー機能
  * 25分（作業）と5分（休憩）の状態管理および自動または手動切り替え
  * 開始、一時停止、リセットのコントロール
  * リアルタイムのカウントダウン表示
* 作業内容およびカテゴリの記録機能
  * タイマー開始前のカテゴリ選択または入力と、簡単な作業内容のテキスト入力
  * 1ポモドーロ完了ごとの、カテゴリ、作業名、完了サイクル数のログ蓄積
* 振り返りダッシュボード
  * 今日実施したカテゴリおよび作業内容ごとの累計サイクル数の一覧表示

## 3. スコープ外
* 外部データベースやクラウドへの保存（アプリ起動中のメモリ保持、または終了時の簡単なローカルファイル保存に留める）
* 過去の長期的（週単位や月単位）なグラフ分析
