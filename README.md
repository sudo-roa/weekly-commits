# weekly-commits 

毎週（基準）のプログラミングのアウトプットを継続的に積み上げるリポジトリ<br>
*A repository for building and archiving one coding project every week to maintain a consistent habit.*

## 📌 概要 (Overview)
1週間につき1つのアウトプット（ツール、アプリ、スクリプトなど）を計画から実装まで一通り回し、開発力の向上とプログラミング習慣の維持を目指します。

## 🔄 進め方 (Workflow)
毎週のアウトプットは以下の開発サイクルに沿って進めます。

1. **テーマを決める**: その週に作る対象や、試したい技術・アイデアを設定する。
2. **要件定義をする**: 何ができるものを作るか、それに必要な機能は何かを明確にし、ゴールを設定する。
3. **設計する**: ディレクトリ構成、データ構造、処理の流れ等を整理する。
4. **実装する**: `week-XX` フォルダ内でコーディングを行い、動く形にする。
5. **テスト**: 意図通りに動作するか検証・テストコードの作成を行い、品質を担保する。
